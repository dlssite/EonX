# Sitemap Strategy — Eonrisia

## Generation

The sitemap is auto-generated by Next.js using `app/sitemap.ts`. It fetches all published dynamic routes from Payload at build time and combines them with static routes.

```ts
// app/sitemap.ts
import { MetadataRoute } from 'next'
import { getPayload } from 'payload'
import config from '@payload-config'

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const payload = await getPayload({ config })

  const { docs: projects } = await payload.find({
    collection: 'projects',
    where: { isPublished: { equals: true } },
    select: { slug: true, updatedAt: true },
  })

  const staticRoutes: MetadataRoute.Sitemap = [
    { url: 'https://eonrisia.org',            changeFrequency: 'weekly',  priority: 1.0 },
    { url: 'https://eonrisia.org/about',       changeFrequency: 'monthly', priority: 0.8 },
    { url: 'https://eonrisia.org/mission',     changeFrequency: 'monthly', priority: 0.8 },
    { url: 'https://eonrisia.org/team',        changeFrequency: 'weekly',  priority: 0.7 },
    { url: 'https://eonrisia.org/projects',    changeFrequency: 'weekly',  priority: 0.8 },
    { url: 'https://eonrisia.org/volunteer',   changeFrequency: 'weekly',  priority: 0.8 },
    { url: 'https://eonrisia.org/contact',     changeFrequency: 'yearly',  priority: 0.6 },
  ]

  const projectRoutes: MetadataRoute.Sitemap = projects.map((project) => ({
    url: `https://eonrisia.org/projects/${project.slug}`,
    lastModified: project.updatedAt,
    changeFrequency: 'monthly',
    priority: 0.7,
  }))

  return [...staticRoutes, ...projectRoutes]
}
```

---

## Priority Values

| Priority | Meaning | Pages |
|---|---|---|
| 1.0 | Highest — crawl frequently | Home |
| 0.8 | Core pages — important | About, Mission, Projects, Volunteer |
| 0.7 | Supporting pages | Team, Project detail, Blog index |
| 0.6 | Low-change pages | Contact, Governance, Press |
| 0.5 | Individual posts | Blog posts (Phase 2) |

---

## Excluded from Sitemap

The following are never included in `sitemap.xml`:

- `/admin/*` — CMS admin panel
- `/api/*` — API routes
- Draft or unpublished content
- Form confirmation pages (if any)
- Any page with `noindex` meta tag

---

## robots.txt

Generated via `app/robots.ts`:

```ts
// app/robots.ts
import { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      {
        userAgent: '*',
        allow: '/',
        disallow: ['/admin/', '/api/'],
      },
    ],
    sitemap: 'https://eonrisia.org/sitemap.xml',
  }
}
```

## Submission

On launch day:
1. Verify `https://eonrisia.org/sitemap.xml` is accessible
2. Submit the sitemap URL in [Google Search Console](https://search.google.com/search-console)
3. Submit in [Bing Webmaster Tools](https://www.bing.com/webmasters)
4. Log submission date in `docs/08-governance/decision-log.md`
