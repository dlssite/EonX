# Constitution — Eonrisia Website

## What This Is

The Eonrisia Website Constitution is a set of immutable rules that govern the website's identity, technology, and standards. These rules cannot be changed by a single contributor — they require a formal amendment process and team consensus.

The constitution exists because some decisions are foundational. Changing them mid-stream is disruptive, expensive, and often a sign that a team is drifting from its original intent. By writing them down and protecting them, we avoid relitigating the same questions repeatedly.

---

## Relationship to the Docs

The `docs/` folder is living documentation. It is updated regularly as the project evolves.

The `constitution/` folder is law. It changes only through the amendment process defined in [08 Amendment Process](./08-amendment-process.md).

If there is a conflict between `docs/` and `constitution/`, the **constitution prevails**.

---

## Who This Applies To

Every person who contributes to the Eonrisia website repository — core team, volunteers, contractors, and AI agents — is bound by this constitution.
